# asole

A Python command-line utility.

## Requirements

- Python 3.11 or later

## Installation

```bash
pip install asole
```

Or install from source using Poetry:

```bash
git clone https://github.com/conao3/python-asole.git
cd python-asole
poetry install
```

## Usage

```bash
asole
```

## Development

This project uses [Poetry](https://python-poetry.org/) for dependency management.

```bash
# Install dependencies
poetry install

# Run the CLI
poetry run asole
```
